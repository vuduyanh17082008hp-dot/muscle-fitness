# Muscle Fitness — Surprise Features

## 1. Dante

Profile-aware and evidence-aware AI coaching.

Dante is designed to understand more than the user's last message.

Demo:

`/chatbot`

## 2. Adaptive Workout Splits

Clients can choose:

- recommended splits
- Full Body
- Upper / Lower
- Push / Pull / Legs
- hybrid structures
- custom splits

Demo:

Dashboard → Workouts

## 3. Priority Muscle Programming

Clients can specify muscles they want to emphasize.

The program can adjust:

- order
- exercise selection
- volume
- frequency

## 4. RIR and Intensity

The workout builder supports more meaningful programming variables
than simply exercise names.

Potential controls:

- sets
- reps
- RIR
- intensity
- failure preference
- rest

## 5. External Exercise Data

wger can expand the exercise library when the API integration is
active.

## 6. Personalized Nutrition

Nutrition advice can use:

- profile
- calorie targets
- macros
- preferences
- exclusions
- allergies

## 7. Recovery-Aware Coaching

Check-in and recovery information can influence Dante's advice.

## 8. Responsible AI

Muscle Fitness contains an explicit Responsible AI surface.
