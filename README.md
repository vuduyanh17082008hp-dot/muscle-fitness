# Muscle Fitness

Next.js app — **Dự án 09: Workout system** (exercise library, plan builder, workout player, progression).

## Quick start

```bash
npm install
npm run dev
```

- Dashboard: http://localhost:3000/dashboard  
- Hướng dẫn (VI): http://localhost:3000/docs/workout-system  
- Markdown: [`docs/PROJECT_09_WORKOUT_SYSTEM.md`](./docs/PROJECT_09_WORKOUT_SYSTEM.md)

## Completion flow

Open workout → Log every set → Complete workout → Save database → View history → Next-session recommendation

Local DB file: `data/workout-db.json` (auto-created).  
Supabase schema: `supabase/migrations/20260804141000_project_09_workout_system.sql`
